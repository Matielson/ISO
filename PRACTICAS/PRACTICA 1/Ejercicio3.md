Los componentes fundamentales de GNU/Linux son el Kernel, la Shell y el Filesystem. El Kernel es el núcleo del sistema operativo y permite la interacción entre el software y el hardware; la Shell actúa como intérprete de comandos e interfaz entre el usuario y el sistema; y el Filesystem se encarga de organizar y administrar los archivos.

b)

+ FILESYSTEM

La estructura básica de GNU/Linux está formada por Kernel, Shell y Filesystem. El Shell funciona como interfaz entre el usuario y el sistema, interpretando los comandos y comunicándose con el Kernel.

El Kernel es el núcleo del sistema operativo y permite la interacción entre el software y el hardware, gestionando los recursos del sistema.

El Filesystem se encarga de organizar y administrar los archivos mediante una estructura jerárquica que parte del directorio raíz /.
