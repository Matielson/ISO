a) Mencione y explique las características más relevantes de GNU/Linux

Las características más importantes de GNU/Linux son:

Multiusuario: permite que distintos usuarios utilicen el sistema, cada uno con su propio entorno, configuración y permisos.
Multitarea: permite ejecutar y administrar múltiples tareas/procesos simultáneamente.

Además, es portable a diferentes arquitecturas, dispone de distintas interfaces de usuario, posee un sistema de usuarios y permisos, distingue mayúsculas de minúsculas (case sensitive), es de código abierto y sigue la filosofía de que “todo es un archivo”, representando mediante archivos distintos recursos del sistema.

b)

Otros sistemas operativos son Windows y macOS. Al igual que GNU/Linux, ambos son sistemas multitarea, multiusuario y poseen soporte para múltiples unidades de procesamiento, además de mecanismos de usuarios y permisos.

GNU/Linux se diferencia principalmente por ser de código abierto, funcionar sobre una amplia variedad de arquitecturas, disponer de diversas interfaces de comandos y seguir características propias de los sistemas tipo Unix, como la idea de que “todo es un archivo”.

c)

GNU es un proyecto iniciado por Richard Stallman en 1983 con el objetivo de desarrollar un sistema operativo completo, similar y compatible con Unix, pero basado en software libre. El proyecto desarrolló numerosas herramientas, bibliotecas y programas que posteriormente, junto con el kernel Linux, dieron lugar a GNU/Linux.

d)

El proyecto GNU fue iniciado por Richard Stallman en 1983 con el objetivo de desarrollar un sistema operativo similar a Unix pero basado en software libre. Su desarrollo comenzó en 1984 y posteriormente se creó la Free Software Foundation (FSF).

Con el tiempo GNU desarrolló herramientas como GCC, Emacs, bibliotecas y numerosas utilidades, pero en 1990 todavía carecía de un kernel funcional. GNU comenzó el desarrollo del kernel Hurd, aunque este presentó dificultades.

Paralelamente, Linus Torvalds comenzó a desarrollar el kernel Linux en 1991, que posteriormente fue distribuido bajo la licencia GNU GPL.

En 1992, la combinación de las herramientas GNU con el kernel Linux permitió disponer de un sistema operativo libre completo, GNU/Linux.

e)

La multitarea es la capacidad de un sistema operativo para gestionar la ejecución de múltiples tareas o procesos de manera concurrente. GNU/Linux es un sistema multitarea, por lo que permite mantener y administrar varios procesos en ejecución, distribuyendo los recursos del sistema entre ellos.

f)

POSIX (Portable Operating System Interface) es un conjunto de estándares que define interfaces y comportamientos comunes para sistemas operativos tipo Unix. Su objetivo principal es facilitar la compatibilidad y portabilidad de programas entre diferentes sistemas operativos que respeten dichos estándares.

POSIX = ESTÁNDAR → COMPATIBILIDAD SIST. UNIX → PORTABILIDAD SOFTWARE.
